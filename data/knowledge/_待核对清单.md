## 三、可以直接导入的现有资料

把学校已有的公开文件复制进 `data/knowledge/` 即可自动参与检索：

- 招生简章（PDF 请先转成文本或 Markdown）
- 新生入学须知
- 学生手册
- 教务处办事指南
- 学校官网“学校简介”“院系设置”页面正文
- 历年就业质量报告

支持格式：`.md`、`.txt`、`.csv`、`.json`、`.jsonl`。
新增或修改文件后，需要执行一次重建索引：

```bash
curl -X POST http://127.0.0.1:8000/api/admin/reindex -H "X-Admin-Token: 你的令牌"
```

## 四、免责与合规提醒

1. 不要向知识库投喂包含个人隐私（身份证号、手机号、成绩单）的文件。
2. 招生录取相关表述不要出现“保证录取”“包过”等承诺性用语。
3. 涉及金额、时限的表述必须与学校正式文件完全一致。
4. 对外发布前，建议由学校宣传部门和法务（或校办）审阅话术。
