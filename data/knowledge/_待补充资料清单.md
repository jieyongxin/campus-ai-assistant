# 还需要向学校索取的资料清单

> 本文件以 `_` 开头，**不会进入检索库**，只作为补资料的工作清单。
> 每补一份，按最后一节重建索引即可生效。

## 为什么要补

现在知识库里的内容全部来自学校官网公开信息与 2025 年招生章程，
所以它能准确回答"章程里写过的东西"。而考生和家长真正问得最多、
但章程里没写的那些，就是下面这份清单。

**原则上只收学校已经公开的资料**，不要放内部文件或含个人隐私的文件。
PDF 需要先转成文本或 Markdown 再放进 `data/knowledge/`。

## 第一优先：招生季用得上

| 资料 | 从哪拿 | 补上之后能回答 |
| --- | --- | --- |
| 当年招生简章 / 招生章程全文 | 招生就业处、学校官网 | 招生计划、录取规则、特殊类型要求 |
| 分省分专业招生计划表 | 招生就业处 | "你们在河南招多少人""有没有这个专业" |
| 历年录取分数线（分省分专业） | 招生就业处、各省考试院 | "去年多少分能上"（目前只能回答"无法预测"） |
| 新生入学须知 / 入学指南 | 学生处、随录取通知书寄送 | 报到时间地点、需带材料、缴费流程、军训安排 |
| 各专业介绍（培养目标、核心课程、就业方向） | 各学院、官网招生栏目 | "这个专业学什么""好不好就业" |
| 学费住宿费备案文件 | 财务处 | 各专业精确学费（现在是按门类给的区间） |

## 补充资料的操作步骤

1. 把文件（`.md` / `.txt` / `.csv` / `.jsonl`）放进 `data/knowledge/`。
   PDF 请先转成文本或 Markdown；Word 建议另存为纯文本。
2. 重建索引：

   ```powershell
   $env:PYTHONPATH=".libs"; python scripts\build_index.py
   ```

3. 跑一遍回归，确认新增资料没有让原有问答变差：

   ```powershell
   python scripts\qa_regression.py
   ```

4. 针对新补的资料，往 `08-常见问答.csv` 里加几条**用户会怎么问**的问答，
   这一步对提升命中率最有效——因为问答表会把问题原文一起入库。

## 也可以反过来做：让系统告诉你缺什么

服务运行一段时间后，`/api/admin/misses` 会列出**所有没答上来的问题**，
这就是最真实的补料清单，比凭猜测列清单准得多：

```powershell
curl "http://127.0.0.1:8000/api/admin/misses?days=30" -H "X-Admin-Token: 你的令牌"
```
