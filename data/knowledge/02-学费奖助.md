# 学费、住宿费与奖助体系

> 以下标准来自《滇池学院 2025 年普高类招生章程》。当年实际收费以云南省发改委、教育厅备案标准和录取通知书、新生入学须知为准。

## 学费标准（2025 级）

| 学科门类 | 学费（元/生·学年） |
| --- | --- |
| 文学、教育学本科专业 | 20000 |
| 经济学、法学、管理学、理学、工学本科专业 | 22000 |
| 艺术学本科专业 | 29000 |
| 高职（专科）专业 | 18000 |

举例：汉语言文学、汉语国际教育、英语、日语、泰语、新闻传播学类等属文学门类，20000 元/年；法学、经济学、金融学、会计学、计算机科学与技术、土木工程等属经法管理工门类，22000 元/年；音乐表演、舞蹈学、视觉传达设计等艺术专业 29000 元/年。

## 住宿费标准

- 学生公寓 4 人间：1200 元/生·学年
- 学生公寓 6 人间：800 元/生·学年
- 普通宿舍：300 元/生·学年

最终分配的宿舍类型以学校后勤安排和新生入学须知为准。

## 缴费方式

1. 新生通过学校迎新系统/统一支付平台缴费，具体渠道以《新生入学须知》为准。
2. 缴费时间以入学须知公布的时间段为准，**请勿向任何个人账户转账**。
3. 家庭经济困难的新生可先通过"绿色通道"办理入学手续，再按规定缓缴或申请资助。

## 奖学金体系

学校建立了"奖、助、贷、勤、补、免"双轨资助体系：

| 类别 | 名称 | 金额（元/生·学年） |
| --- | --- | --- |
| 国家 | 国家奖学金 | 10000 |
| 国家 | 国家励志奖学金（家庭经济困难且品学兼优） | 6000 |
| 云南省 | 云南省政府奖学金 | 6000 |
| 云南省 | 云南省政府励志奖学金 | 4000 |
| 学校 | 滇池学院优秀学生奖学金·特等奖 | 奖励所学专业一学年学费 |
| 学校 | 滇池学院优秀学生奖学金·一等 | 3000 |
| 学校 | 滇池学院优秀学生奖学金·二等 | 2000 |
| 学校 | 滇池学院优秀学生奖学金·三等 | 1000 |
| 学校 | 考取研究生激励奖学金 | 最高 50000 |
| 学校 | 学科竞赛奖学金 | 最高 200000 |

此外还有校级优秀学生干部奖学金和各类单项奖学金。

奖学金一般在**每年 10 月**集中评定上一学年的奖项，具体通知以学生处和各学院发布为准。

## 助学金与助学贷款

- **国家助学金**：一等 4200 元/生·学年，二等 3200 元/生·学年，面向家庭经济困难学生。
- **生源地信用助学贷款**：入学前向户籍所在地县级学生资助管理中心申请，最高 20000 元/生·学年。
- **勤工助学**：学校设有校内勤工助学岗位，通过学生资助管理中心申请。
- **临时困难补助**：因突发事件导致家庭经济困难的，可向所在学院申请。

## 应征入伍与基层就业

- 应征入伍和退役士兵学生享受学费补偿、学费减免，最高 20000 元/生·学年；在校期间享受退役士兵国家助学金 3700 元/生·学年。
- 符合条件的基层就业毕业生可申请基层就业学费补偿、助学贷款代偿；符合条件的毕业生可申请云南省求职补贴。
